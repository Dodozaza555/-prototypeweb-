# ป้องแป๋งนมสด — Table & Queue Matching (Prototype)

เว็บต้นแบบ (prototype) สำหรับระบบสั่งเมนู เลือกโต๊ะ และจองคิวของร้านป้องแป๋งนมสด
ทำขึ้นเพื่อแก้ปัญหาการจัดสรรโต๊ะและการรอคิวของลูกค้า โดยเฉพาะช่วงเวลาที่ลูกค้าเข้าร้านจำนวนมาก

## ฟีเจอร์หลัก

1. **สมัคร/เข้าสู่ระบบสมาชิก** — ด้วยเบอร์โทรและชื่อเล่น เพื่อสะสมแต้ม
2. **เลือกเมนู** — แบ่งหมวดนมสด / น้ำเต้าหู้ / ขนมปังปิ้ง / เต้าฮวย-ไอศกรีม พร้อมเลือกความหวาน (50% / 70% / 100%) และท็อปปิ้ง รวมถึงเซ็ตเมนูแนะนำตามงบประมาณ
3. **เลือกโต๊ะ** — แผนผังร้านแบบ 2D/3D แบ่งโซน A (1–3 คน) / B (3–5 คน) / D (6–10 คน) พร้อมสถานะโต๊ะแบบเรียลไทม์ และตัวเลือกอนุญาตให้นั่งร่วมโต๊ะ
4. **ยืนยันออเดอร์ & ชำระเงิน** — เลือกจ่ายผ่าน PromptPay QR ทันที หรือจ่ายที่เคาน์เตอร์ภายหลัง
5. **รอคิวโต๊ะ** — แสดงเวลารอโดยประมาณ พร้อมระบบแจ้งเตือนเมื่อถึงคิว

## เปิดดูเดโม

เว็บนี้เป็นไฟล์ HTML/CSS/JS ล้วน ไม่มี backend เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที
หรือถ้าเปิด GitHub Pages ไว้ จะดูผ่านลิงก์ `https://<username>.github.io/<repo-name>/` ได้เลย

> โปรเจกต์นี้เป็นเวอร์ชันต้นแบบสำหรับสาธิตแนวคิด (prototype) ยังไม่มีระบบหลังบ้านจริง
